## 🛠️ Herramientas Online Esenciales

### OSINT, Dominios e Infraestructura Cloud
* [Phonebook.cz](https://phonebook.cz) - Búsqueda de emails, dominios y URLs públicas.
* [Shodan.io](https://www.shodan.io/) - Buscador de dispositivos conectados a Internet (IoT, servidores, bases de datos).
* [Domain.Glass](http://domain.glass) - Mapeo detallado de infraestructura de dominios y hosts.
* [GrayHatWarfare](https://buckets.grayhatwarfare.com/) - Buscador público de buckets abiertos (AWS S3, Azure Blobs).
* [ViewDNS.info](https://viewdns.info/) - Herramientas de DNS reverse, WHOIS y detección de spam.
* [Hunter.io](https://hunter.io/) - Búsqueda de correos corporativos por dominio.
* [Intelx.io](https://intelx.io) - Buscador de datos filtrados y OSINT.
* [Crt.sh](https://crt.sh/) - Búsqueda de certificados SSL/TLS para descubrir subdominios.

### Criptografía y Cracking
* [Crackstation](https://crackstation.net) - Base de datos masiva para romper hashes (MD5, SHA1, etc).
* [Dcode.fr](https://dcode.fr) - Identificador y decodificador de cifrados clásicos y modernos.
* [CyberChef](https://gchq.github.io/CyberChef/) - Manipulación y transformación de datos (Base64, Hex, URL encode, XOR).

### Shells, Payloads y Repositorios de Explotación
* [Revshells](https://www.revshells.com/) - Generador dinámico de Reverse Shells multidispositivo.
* [Pentestmonkey](https://pentestmonkey.net) - Referencia clásica de cheatsheets y webshells.
* [GTFOBins](https://gtfobins.github.io/) - Binarios de Linux para escalada de privilegios y bypass.
* [LOLBAS](https://lolbas-project.github.io/) - Binarios de Windows para evasión, transferencia y persistencia (Living Off The Land).
* [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Repositorio exhaustivo de payloads para web, redes y post-explotación.
* [Mythic](https://github.com/its-a-feature/Mythic) - Framework C2 colaborativo y modular para operaciones Red Team (Alternativa a Metasploit/CobaltStrike).
* [Nishang](https://github.com/samratashok/nishang) - Scripts y payloads de PowerShell para todas las fases del pentesting.
* [Darkarmour](https://github.com/bats3c/darkarmour) - Generador de binarios de Windows ofuscados con cifrado para evasión de AV.
* [WhiteWinterWolf PHP WebShell](https://github.com/WhiteWinterWolf/wwwolf-php-webshell) - WebShell avanzada en PHP con interfaz gráfica e interactividad.

## 🎓 Plataformas para Practicar (CTFs)
* [HackTheBox](https://www.hackthebox.com/) - Máquinas de alta calidad, desafíos y laboratorios de Active Directory.
* [DockerLabs](https://dockerlabs.es/) - Laboratorios basados en Docker, muy rápidos de desplegar localmente.
* [TryHackMe](https://tryhackme.com/) - Rutas de aprendizaje guiadas y salas temáticas.
* [Vulnyx](https://vulnyx.com/) - Máquinas en español muy recomendadas.
* [VulnHub](https://www.vulnhub.com/) - Catálogo clásico de máquinas virtuales vulnerables (OVA).
* [HackMyVM](https://hackmyvm.eu/) - Plataforma competitiva y variada.
